### 线 D · 安装器核心（关键路径）

**交付：** `mipl_installer` 用命令行跑通「空盘 → 能启动的系统」，全程只在 `out/target.qcow2` 上。

- `disk.py`：擦盘 → GPT → ESP 512 MiB + root
- `packages.py`：`pacstrap` 到 `/mnt`
- `configure.py`：fstab / locale / 用户 / `pacman-key` / mirrorlist / chroot 内 `mkinitcpio -P`
- `boot.py`：`bootctl install` + loader entry（只写需要显式覆盖的内核参数）+ `efibootmgr`

**验收：** `mipl qemu --disk target.qcow2 --boot c` 能进系统（检查点 4），进去 `pacman -Syu` 成功（检查点 6）。
**依赖：** 在 Live 里跑要等线 E 把 `python-pyparted` 加进清单；在那之前可以先用容器/宿主里的同一份代码练逻辑。
**不碰：** 界面、Live 包清单。

### 线 E · Live 环境与入口（M0）

**交付：** QEMU 开机直进一个全屏窗口（占位即可），杀掉它能落回 TTY。

- 包清单加 `networkmanager`、`cage`、`qt6-wayland`、`pyside6`、`python-pyparted`
- kiosk unit：`cage` 拉起 `installer/bin/mipl-installer`，`Restart=on-failure`；`getty` autologin 保留为兜底
- NetworkManager 的无 GUI 配置
- `baseline-build.sh` 把 `installer/` 拷进 airootfs；`mipl.sh` 加 `installer` 子命令（建盘 + 启动 + 串口日志）
- 占位的 PySide6 全屏窗口 —— 真界面是 M2，等线 D 的事件流

**验收：** QEMU 里开机看到窗口；`systemctl kill` 之后落回 root TTY；`journalctl -u` 有日志。
**协调：** `packages.x86_64` 与 `airootfs` 的网络配置**等移除 `iwd` 的那条分支合入后再改**，
避免同一批文件两边改重。

### 线 F · 真机与桌面

**交付 1（别等安装器）：** 真机上 Live 能加载 `nvidia-open` —— 依据是
[04-架构决策](../knowledge/04-架构决策.md) 第 1.6 节。
**交付 2：** niri 与 Hyprland 各跑一轮，给 P5 一个结论（倾向即可）。只测三件事：
**驱动能亮、输入法能打字、中文能显示**。
**产出：** `docs/work/tech/05-装后系统验证.md` —— 先写 Live 那半段，装后系统那半段等线 D。
