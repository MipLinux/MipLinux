# AGENTS.md — docs/ 文档标准

这个项目的文档是技术资产。文档写错的代价比代码更高 —— 维护者在两台不同的机器上照着它操作。
本文只写 `docs/` 特有的规矩；通用红线在[根文件](../AGENTS.md)。

## 文档红线

1. **一条结论一个出处。** 其他位置给链接。
2. **文档不记历史。** 改了就把旧正文删掉。
3. **只写结论，不写实现。** 代码、配置原文、日志、版本计数各有去处，不进结论。
4. **只写现在，不写否定。** 禁止出现「不再用 X」「已改回 Y」或类似句子。
5. **精简用词。** 能多精简你的用语，就不要写的复杂。

# 各层职责

| 层 | 放什么 | 不放什么 |
|---|---|---|
| `knowledge/` | 当前结论，给新手读 | 待解决、修订痕迹、出局候选、原始输出 |
| `06-待定事项.md` | 未定问题，P 编号：背景 / 候选 / 影响面 | 已定案 D、已否决方案正文 |
| `work/` | issue 规范与骨架、ROADMAP、可复现实测步骤 | 已定案结论、与 issue 重述的分工 |
| `archive/` | 已解决 / 已分流记录：症状 / 证据 / 根因 / 修法 | 未定决策、计划待办 |

定案单向：`06` 的 P → 定案后登记为 D → `06` 只留推导与排除表。  

D 是决策史：一个决定一个号，改主意不换号、不销号。  

登记入口已断：D 往哪登记由维护者定；定前不照抄旧口径，也不新建表。  

未定问题走 issue，不进 `knowledge/`。

# README

- 根 `README.md`：项目是什么、用户怎么用、进度表、四条原则。  
  不写：导航、脚本清单、目录内部细节。
- `docs/README.md`：文档总入口，只指路，不写结论。
- 各目录 `README.md`：本目录是什么、怎么读、规矩。
- 本文件：写法规矩。

进度表用大白话，唯一源在根 `README.md`。  
不写内部术语与记号：里程碑号、检查点编号、D / P 编号、单测条数、代码等。

# 决策变更

- 一个编号只有一份正文，永远只留定案版。
- 旧决策直接删掉，不留对照。禁止出现“从A改为B”，“没有回退到A”或类似描述
- 已登记 D 的改动 = 改项目约束：先问人。新决策先 P 进 `06`，定案后升 D。
- 想知道为何否决 → 排除表或 `archive/`，写完整理由，不写“原 X 改 Y”。
- 不写迁移说明：“已更新”“以本节为准”“旧版作废”都是噪音。
- `knowledge/` 只写现在是什么，用现在时，不写“曾是 / 改为”。

# 写结论，不写实现

- 不写某台机器状态。改成：怎么在自己机器上查 + 看到什么算合格。
- 能从代码、配置、产物读出来的，不抄进文档。只留读不出的判断：为什么、边界、不做什么。
- 数字只写结构事实；测量值不写，给命令或放 `work/tech/` 并注明日期。
- 路径、函数名、包名只在结论本身需要时写，其余指向层级或术语表。
- 不贴代码块、配置原文、日志、原始输出。证据放 `work/tech/` 或 `archive/`。
- 不列逐条命令清单。操作步骤写 `work/tech/`，文档给脚本命令。
- 手工命令只允许出现在排错语境，作为反面教材。
- 不复述脚本内部步骤与检查项。写“失败时看哪里”。

# 写作约定

- 提到人用角色称呼：维护者、贡献者。
- 工作、分工、待办放 GitHub Issues，结论旁不留待办。
- 一条工作 = 一个 issue（label `task`）。草案按 `work/TEMPLATE.md`，存 `out/issue-drafts/`，跑 `./scripts/check-work-issue.sh`。
- `archive/` 按 `YYYY-MM-DD-主题.md`，一篇一役，写为什么和怎么查出，不复制代码。
- 实测结果写 `work/tech/`，不把“跑过一次”当“验过”。
- 文档改动 PR 也要写验证方式；纯文档可写 `N/A`，不留空。

# 交稿前自查

- [ ] 同一结论 / 编号是否重复？第二次改链接。
- [ ] 是否残留旧决策正文或迁移说明？
- [ ] 是否把待办、分工、待定写进结论？
- [ ] 是否贴代码、配置、日志、版本计数？改成一句结论 + 链接。
- [ ] 是否复述脚本内部步骤、参数、`doctor` 检查项？改成“失败时看哪里”。
- [ ] 是否写某台机器状态？改成“怎么查 + 什么算合格”。
- [ ] 描述现状的句子，去掉“不再 / 曾经 / 已修正”后还成立吗？
- [ ] 改 README 时，导航是否误入根 README？进度表是否含外部读者不懂的记号？
