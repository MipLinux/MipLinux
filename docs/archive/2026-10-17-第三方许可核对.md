# 2026-10-17 · 第三方许可核对（libqalculate / lm_sensors）

> 目的：确认 Caelestia shell（GPL-3.0-only）链接的 `libqalculate`、`lm_sensors`
> 在 Arch 官方二进制包中对应的实际许可声明，并留下版本、commit、文件路径与 SPDX 判断依据。
>
> 结论：按对应版本的上游源码头，`libqalculate` 的库代码是 **GPL-2.0-or-later**；
> `libsensors` 是 **LGPL-2.1-or-later**；`sensors` / `sensors-detect` / `pwmconfig`
> 等工具是 **GPL-2.0-or-later**。均与 Caelestia 的 GPL-3.0-only 兼容。
>
> 处置：继续使用 Arch 官方二进制包，不自行重建；本文是证据，结论同步到 [THIRD-PARTY.md](../../THIRD-PARTY.md)。

## 一、口径

- **Arch 元数据是包级 SPDX 表达式，不是权利人的重新许可。** 判断以对应版本的上游源码头为准。
- 只核对与链接 / 分发判断相关的组件；数据、文档、翻译文件的例外单独记录，不混入库代码结论。
- 版本与 commit 是本次核对的对象；Arch 滚动更新后重新核对，不把旧结论当永久事实。
- 记录的是“声明在哪里、原文是什么、对应哪个版本”，不复制源代码。

## 二、libqalculate

| 项 | 值 |
|---|---|
| Arch 包 | [`libqalculate 5.13.2-1`](https://archlinux.org/packages/extra/x86_64/libqalculate/)（extra） |
| Arch 元数据 | `GPL-2.0-only` |
| 上游 tag | [`v5.13.2`](https://github.com/Qalculate/libqalculate/tree/v5.13.2) |
| commit | [`d3672af9cf6e05a39bd4206b7b7d6b1e0d194caa`](https://github.com/Qalculate/libqalculate/commit/d3672af9cf6e05a39bd4206b7b7d6b1e0d194caa) |
| 声明文件 | [`libqalculate/Calculator.h`](https://github.com/Qalculate/libqalculate/blob/v5.13.2/libqalculate/Calculator.h)、[`libqalculate/includes.h`](https://github.com/Qalculate/libqalculate/blob/v5.13.2/libqalculate/includes.h)；另抽查 `Calculator.cc`、`Number.cc` |
| 声明原文 | “either version 2 of the License, or (at your option) any later version” |
| SPDX 判断 | **`GPL-2.0-or-later`**（库代码） |
| Arch PKGBUILD | [`source=git+https://github.com/Qalculate/libqalculate#tag=v5.13.2`](https://gitlab.archlinux.org/archlinux/packaging/packages/libqalculate/-/blob/main/PKGBUILD)，无补丁 |
| 辅助证据 | Fedora rawhide spec 5.11.0：`GPL-2.0-or-later and LicenseRef-Fedora-Public-Domain and GFDL-1.1-or-later`；Homebrew 5.13.1：`GPL-2.0-or-later` |

**判断依据：**

- 仓库根 `COPYING` 是 GPLv2 正文；**“or later” 的授权在源码头文件里**，不在 `COPYING` 正文本身。
- Arch 的 `GPL-2.0-only` 是包级保守标注；PKGBUILD 从 `v5.13.2` 直接构建，没有改许可的补丁，
  不能把它当成对上游代码的重新许可。
- Fedora spec 明确写“整个源码是 GPL-2.0-or-later，除了”：
  `po/libqalculate.pot`、`po-defs/libqalculate.pot`（Fedora Public Domain）与
  `data/planets.xml.in`（GFDL-1.1-or-later）。这些是数据 / 翻译文件，不影响库代码链接判断。
  Fedora spec 的版本是 5.11.0，属于辅助证据，不是 5.13.2 的替代。
- Homebrew formula 当前是 5.13.1，比 Arch 的 5.13.2 低一个补丁版本；只作辅助证据。
- 兼容性：`GPL-2.0-or-later` 可以按 GPLv3 使用；Caelestia shell 的 GPL-3.0-only 链接它不冲突。

## 三、lm_sensors

| 组件 | 声明文件 | 上游声明 | SPDX 判断 |
|---|---|---|---|
| `libsensors` | [`lib/sensors.h`](https://github.com/lm-sensors/lm-sensors/blob/V3-6-2/lib/sensors.h)（另抽查 `lib/data.c`、`lib/error.c`、`lib/access.c`） | LGPL 2.1 or later | **`LGPL-2.1-or-later`** |
| `sensors` CLI | [`prog/sensors/main.c`](https://github.com/lm-sensors/lm-sensors/blob/V3-6-2/prog/sensors/main.c) | GPL v2 or later | **`GPL-2.0-or-later`** |
| `sensors-detect` | [`prog/detect/sensors-detect`](https://github.com/lm-sensors/lm-sensors/blob/V3-6-2/prog/detect/sensors-detect) | GPL v2 or later | **`GPL-2.0-or-later`** |
| `pwmconfig` | [`prog/pwm/pwmconfig`](https://github.com/lm-sensors/lm-sensors/blob/V3-6-2/prog/pwm/pwmconfig) | GPL v2 or later | **`GPL-2.0-or-later`** |
| 其余 `prog/` 工具 | 各文件头 | 以 GPL-2.0-or-later 为主 | 发布前逐文件核对 |

`libsensors` 的文件头原文是 “GNU Lesser General Public License … either version 2.1 of the License,
or (at your option) any later version.”；`sensors` / `sensors-detect` / `pwmconfig` 是
“GNU General Public License … either version 2 of the License, or (at your option) any later version.”

- Arch 包：[`lm_sensors 3.6.2-1`](https://archlinux.org/packages/extra/x86_64/lm_sensors/)（epoch 1），
  上游 tag `V3-6-2`，commit [`5c3ba50f806dea27c3b1e368966191c735459111`](https://github.com/lm-sensors/lm-sensors/commit/5c3ba50f806dea27c3b1e368966191c735459111)。
- Arch 元数据写 `GPL-2.0-only OR LGPL-2.1-only`，这是**包级表达式**，不是每个文件的结论；
  不能把它直接照搬成 `libsensors` 或 `sensors` 的 SPDX。
- Arch PKGBUILD 从上游 `V3-6-2` tarball 构建；[`prepare()`](https://gitlab.archlinux.org/archlinux/packaging/packages/lm_sensors/-/blob/main/PKGBUILD) 只改 `/etc/sysconfig` 路径和 systemd
  `EnvironmentFile`，**不改许可头**。
- 兼容性：`libsensors` 的 LGPL-2.1-or-later 可按 LGPLv2.1 §3 转 GPLv3 使用；
  `sensors` 等工具是 GPL-2.0-or-later，可升级到 GPLv3；工具通常是独立进程，不改变 Caelestia 的许可。
- “其余 `prog/` 工具”没有逐文件穷举；发布前用文件头逐项核对，不把本表当成全部组件的最终清单。

## 四、NVIDIA EULA 证据

这一节只记录版本与校验，许可分析见 [THIRD-PARTY.md](../../THIRD-PARTY.md) 的 NVIDIA 部分。

| 项 | 值 |
|---|---|
| 核对对象 | `out/miplinux-2026.10.17-x86_64.iso` 的 `airootfs.sfs` |
| `nvidia-utils` | `615.78.08-1` |
| EULA 路径 | `/usr/share/licenses/nvidia-utils/LICENSE` |
| EULA 版本 | `(v. February 25, 2025)` |
| EULA sha256 | `c692fb14ad4f499c6aee1b9e144e6905148c420e6225b17cb2937366c1e507ad` |
| `nvidia-open` | `615.78.08-2` |
| `nvidia-open` 许可路径 | `/usr/share/licenses/nvidia-open/LICENSE` |
| `nvidia-open` 许可 sha256 | `d8e96d29bc323000e7ba56102d77c88226a7a3d0d94e2081cb4b071ae9de4a06` |

- `nvidia-open` 的许可文本写明 “Except where noted otherwise … MIT”；Arch 元数据是
  `MIT AND GPL-2.0-only`。**预装 `nvidia-open` 不等于整栈开源**，用户态 `nvidia-utils` 仍是专有。
- Arch `nvidia-utils` 的 [PKGBUILD](https://gitlab.archlinux.org/archlinux/packaging/packages/nvidia-utils/-/blob/main/PKGBUILD)
  明确 `options=('!strip')`；`package_nvidia-utils()` 用 `install -Dm755` 原样安装用户态库，
  没有 `strip` / `patchelf`，`prepare()` 的 `sed` 只改开放内核模块的 `utils.mk` / `dkms.conf`，不碰用户态二进制。
  这一点是 EULA 1.1(d)“二进制不得修改”的直接证据。
- 再分发依据是 EULA 1.1(d)：随 OSI 许可的 Linux 内核、二进制不改、协议随附；2.9 的聚合边界、
  2.8 的 GeForce/TITAN 范围、2.11 的 indemnity、11/12 的责任上限见 THIRD-PARTY。
- NVIDIA 二进制不做 `strip` / patch / 重打包；保留 EULA，并记录包版本与许可证 sha256。
  本次记录的是许可证文件 sha256；发布时再记录 `nvidia-utils` 包文件 / 关键库的 sha256，作为二进制完整性证据。
