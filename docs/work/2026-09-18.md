## 已踩过的坑（执行前先看，能省时间）

两条 nspawn 相关的坑，都已写进 [tech/01-容器环境搭建.md](tech/01-容器环境搭建.md)：

| 问题 | 原因 | 要点 |
|---|---|---|
| 停在 `archbuild login:` 进不去 | 命令带了 `-b`，而 bootstrap 的 root 无密码（`root:*:`） | **去掉 `-b`，用 `-u root`** |
| 报 `Mount point '.../unix-export' exists already` | 机器名 `archbuild` 被上一个未退出的容器占用 | **先 `machinectl poweroff archbuild`** |

**关键概念：容器不会因为关闭终端而停止。** 它由 systemd 作为 `archbuild.scope` 管理，关窗口只是断开连接。每次用完必须显式关机：

```bash
# 容器内
poweroff
# 或宿主机上
sudo machinectl poweroff archbuild
```

**不要按 `Ctrl+]` 三次**（或直接关窗口）——那会留下残留状态，就是上面第二个坑的成因。详见 tech/01 的「容器生命周期」一节。
