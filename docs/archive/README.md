# docs/archive · 问题记录（归档）

这里放**已经解决、或已经分流成 issue** 的问题记录：症状、排查过程、根因、修法、教训。

**为什么单列一层：** 这些内容既不是「已确定的结论」（[knowledge](../knowledge/) 只讲现在该怎么做，
不留修订痕迹），也不是「待执行的工作」（[work](../work/) 讲接下来做什么）。
它是「**为什么变成现在这样**」的现场记录 —— 给后来的人（包括几个月后的自己）省一遍弯路。

| 放什么 | 不放什么 |
|---|---|
| 踩过的坑：症状 / 证据 / 根因 / 修法 / 教训 | 未定的决策（→ [06 的 P 表](../knowledge/06-待定事项.md)） |
| 排错方法本身（怎么把问题逼出来） | 计划与待办（→ [work/](../work/)） |
| 已提 issue 的分流记录（附链接） | 能提炼成结论的内容（应该写回 `knowledge/`） |

命名：`YYYY-MM-DD-主题.md`，一篇一役。写「为什么」与「怎么查出来的」，不复制代码。
