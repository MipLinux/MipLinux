# 安装器界面视觉方向 · Electron 版

> 状态：**2026-10-04 维护者定**（「不一定要继续用 MD3，面向 C 端用户，尽可能更好看，注意动画」）。
> 本文是实现准据；**[tech/08](08-界面设计方向.md) 的 MD3 规范自此降级为历史参考**（其品牌种子色与附录 A 色板仍是资产）。
> 页面流程、步骤表与 104 条文案不随视觉改动 —— 见 [tech/09](09-安装器界面文案.md)。

---

## 1. 设计读（Design Read）

**面向中文普通用户的整盘安装向导，暗色＝极光玻璃（ethereal glass）、亮色＝柔性结构（soft structuralism）。**
安装器是一次性流程、用户不看第二遍 —— 所以目标不是「信息密度」也不是「品牌铺陈」，而是
**每一步都让人确信「它知道自己在干什么」**：空间要空、字要大、动效要稳、危险动作要吓人。

三个刻度（沿用直觉，不写进代码）：

| 刻度 | 值 | 依据 |
|---|---|---|
| DESIGN_VARIANCE | 6 | 向导需要可预测性；用不对称栅格与错落层级制造高级感，但不做艺术化排布 |
| MOTION_INTENSITY | 7 | 全屏 kiosk 里动效是「系统还活着」的唯一证据；但每一步的动效都要能一句话说出理由 |
| VISUAL_DENSITY | 3 | 一屏一件事。安装器最常见的信息量是一张卡片 + 一个按钮 |

## 2. 双主题（默认跟随本地时间，可锁定 —— 同 tech/08 §3.9）

**默认 = 跟随时间**（维护者 2026-10-04）：07:00–18:59 亮、其余暗；顶栏主题菜单可以**锁定**成
亮或暗（锁定后不再跟时间走）。「亮色为主」指的是**设计基线**（排版、间距、阴影都先按亮色定），
不是把界面钉死在亮色。

| | 暗（19:00–06:59 默认） | 亮（07:00–18:59 默认） |
|---|---|---|
| 底 | `#06070b` 深空黑 | `#f4f6fb` 冷调银白 |
| 极光 | 品牌蓝 → 青 → 深靛，径向叠加，透明度 0.14–0.22 | 同一色相，透明度 0.06–0.10 |
| 面板 | 玻璃：`rgba(255,255,255,.045)` + 1px 高光描边 | 实心白 + 极淡冷阴影 |
| 文字 | `#eef1f8` / 次要 `#9aa4bb` | `#0d1526` / 次要 `#55607a` |
| 强调 | `#5b8dff`（亮蓝），按钮文字用深色 `#06122e` | `#2456d6`，按钮文字用白色 |

**品牌锚点**：种子色仍是 `#2576E9`（来自 logo，见 [tech/08 附录 A](08-界面设计方向.md)）。
极光只用**蓝→青**这一族；**不用紫色**（AI 套路色），也不做彩虹渐变。

## 3. 排版

- 拉丁/数字：**Geist**（vendored，OFL，见 [app/vendor/README.md](../../../installer/frontend/app/vendor/README.md)）；
  中文：Live 自带的 `noto-fonts-cjk`。字体栈写在 `tokens.css` 的 `--font-sans`，**不联网加载**。
- 字号阶梯（px）：`40 / 30 / 22 / 18 / 17 / 15 / 13.5 / 12.5`，行高 1.15（大标题）→ 1.55（正文）。
- 大标题 `letter-spacing: -0.02em`；中文标题字重 600，正文 400。
- 数字一律 `font-variant-numeric: tabular-nums`（磁盘容量、UTC 偏移、计时器）。

## 4. 形状与深度

**一条锁死的圆角规则**（不许混用）：

| 用途 | 半径 |
|---|---|
| 面板外壳（double-bezel 外层） | `26px` |
| 面板内核 | `18px`（= 26 − 8，同心） |
| 输入框 / 列表项 / 代码块 | `14px` |
| 按钮 / 芯片 / 徽标 | `999px` |
| 对话框 | `24px` |

- **双层壳（Doppelrand）**：所有主面板 = 外层（1px hairline + 内阴影高光）套内层（自己的底色）。
  不要把一个平板卡片直接拍在背景上。
- 阴影**染色**：暗色用 `rgba(3,6,18,.55)`，亮色用 `rgba(15,23,42,.08)` —— 不用纯黑投影。

## 5. 动效（编排纪律）

库：**anime.js v4**（vendored，MIT）。原则：

1. **只动 `transform` 与 `opacity`**；不动 `top/left/width/height`。
2. 时长档：`140 / 240 / 420 / 480`ms；缓动 `cubic-bezier(.32,.72,0,1)`（入场）、
   `cubic-bezier(.4,0,1,1)`（出场）。**不用 `linear` / `ease-in-out`。**
3. 页面切换：旧页 160ms 淡出上移 8px → 新页容器 240ms 淡入 + 子块 **40ms 交错**上浮 12px。
4. 微交互：按钮按下 `scale(.98)`；主按钮内嵌图标圈在 hover 时对角位移 2px；
   步骤条填充随进度缓动；危险动作（擦盘）用**减速**而不是加速，制造「不可撤销」的分量感。
5. **`prefers-reduced-motion: reduce` 下全部退化为无位移的即时切换**（CSS 与 JS 双保险）。
6. 背景极光：CSS 层缓慢漂移（60s 级），**不做粒子雨**；不打 `backdrop-filter` 到大面积滚动内容上。

## 6. 版式

- 断点：`< 840` 单列（顶部步骤条 + 内容 + 底部动作区）；`≥ 840` 双列（左侧步骤轨道 300px + 右侧内容）。
- **缩放只有一层**（维护者 2026-10-04）：顶栏缩放菜单 = `自动检测 / 100% / 167% / 200%`，
  落到 CSS 的 `--ui-scale`；**设备层缩放（1x/2x/3x）不再单独生效** —— 两层相乘会把 4K 屏推到 4x。
  自动档由启动器按分辨率推荐（`theme/device_scale.py: recommend_ui_scale_percent`，
  判据是「逻辑宽度落在 1536 附近」：2560×1600 → 167%、3840×2160 → 200%、1920×1080 → 100%）。
- 内容区最大宽 `1120px`，两侧留白随视口增长；**一屏一主按钮**（P1 不变）。
- kiosk 全屏无边框；所有可点目标 ≥ 48dp（触屏与 V8 的要求）。

### 6.1 留白与滚动（2026-10-05 实机定）

- **一个 `--gutter` 管所有留白**：窗口四周、行列间距、面板内边距、动作区分隔线两侧 ——
  全部 `calc(var(--space-5) * var(--ui-scale))`。上下与左右必须同值（曾经是 40/53/27 四套数，被实机指出来）。
- **滚动的应该是列表，不是页面**：`panel--fill` → `.panel__core` → `.list-wrap` → `.list` 一路
  `flex: 1; min-height: 0`，**每一环都不能少**（少一环面板就按内容高度长，把页面撑出滚动条）。
  页头、搜索框、扫描按钮、动作区全部固定不动。
- **滚动渐隐由位置决定**：`dom.js: attachScrollFade()` 打 `data-scroll-fade = none|top|bottom|both`，
  只在**确实还有内容**的那一侧加遮罩。不用滚的列表一律 `none` —— 固定遮罩会啃掉最后一项。
- **滚动条不占位也不可见**（滚动照旧），焦点环只留一层（容器负责，输入控件不再叠 outline）。

## 7. 无障碍与硬判据

- 正文对比度 ≥ 4.5:1，大字/图标 ≥ 3:1 —— 由 `app/tools/check-contrast.py` 断言（沿用 tech/08 V2 的方法）。
- 键盘全程可达（V3 的目标不变）：焦点环 2px 强调色 + 2px 偏移，`:focus-visible` 才显示。
- 表单：标签在输入框**上方**，错误在下方；**不用 placeholder 当标签**。
- 空 / 加载 / 错误三态都要有画面（不是只有「成功态」）。

## 8. 组件清单（沿用 tech/08 §4.1 的 17 项，视觉重做）

`app bar`（品牌 + 语言/主题/缩放）· `button`（filled / tonal / text / danger）· `card`（双层壳）·
`dialog` · `text field` · `checkbox` · `radio` · `switch` · `segmented` · `chip` · `badge` ·
`list item` · `menu` · `divider` · `linear progress`（步骤进度 + 安装进度）· `tooltip` · `snackbar`。
新增：`step rail`（左侧步骤轨道）· `aurora backdrop`（背景层）。

**不做**（同 tech/08 §4.2）：日期选择器、富文本、虚拟列表、手势库、世界地图。
